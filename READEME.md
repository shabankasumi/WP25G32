# 🛠️ Local Services Manager

A web application built with ASP.NET Core MVC for managing local services and providers.

## 🚀 Tech Stack

* ASP.NET Core MVC
* C#
* MSSQL

## ✨ Features

* Manage service providers
* Add, update, and delete services (CRUD)
* User management
* Database integration
* Structured MVC architecture

## ⚙️ Run

* Open the project in Visual Studio
* Configure database connection
* Run the application
